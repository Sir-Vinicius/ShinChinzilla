# Shin Chinzilla

Projeto de jogo desenvolvido utilizando Unity 3D.

## Tecnologias

- **Engine:** Unity 6000.3.23f1
- **Versionamento:** Git e GitHub
- **Asset:**

## Como executar o projeto

### Pré-requisitos

- Unity Hub
- Unity Editor na versão `6000.3.23f1`
- Git instalado na máquina

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/Sir-Vinicius/ShinChinzilla.git
   ```

2. Abra o Unity Hub e selecione **Add project from disk** (Adicionar projeto do disco).
3. Selecione a pasta `ShinChinzilla` clonada.
4. Abra o projeto utilizando a versão `6000.3.23f1` da Unity.
5. No editor, abra a cena inicial ou a cena de teste desejada pela janela **Project**, dentro de `Assets/Scenes`.
6. Pressione **Play** para executar a cena.

Caso o projeto apresente problemas relacionados à versão da Unity ou a pacotes, confira a versão do editor e as dependências configuradas no projeto.
